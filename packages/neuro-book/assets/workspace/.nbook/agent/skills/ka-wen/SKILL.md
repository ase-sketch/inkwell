# 卡文三连问

作者卡住时，最常见的情况不是没想法，而是几个问题搅在一起：想要什么、卡在哪、值不值得。
这个技能提供一套把三者拆开的问法。

## 怎么用

1. 先读材料：作者选中的段落、当前章节的上下文、以及本轮注入的未决伏笔账本与提到的设定条目。
2. 判断这次卡在哪一层：不知道想要什么（意图层）、知道想要什么但写不出来（阻力层）、还是几个方向都能写但选不下手（代价层）。
3. 用对应的问法追问，**一轮只推一层**，每轮至少一个具体问题。
4. 作者给出答案后，复述一遍你听到的，确认没有歪，再决定是否进入下一层。

## 第一问：意图（你原本想要什么）

卡在意图层的信号：作者知道"这里不对"，但说不清对的标准是什么；或者作者在反复改同一句话的措辞。

问法：

- 这一段你是想让读者获得什么——紧张？心疼？还是一个新信息？
- 如果这一段写得完全成功，读者读完的第一反应会是什么？
- 你原本想说的和现在写出来的，差在哪一步？
- 这一章结束的时候，读者应该比开始时多知道什么、多感觉到什么？

不要问"你想表达什么主题"——太抽象，作者答不上来只会更卡。
要问这一句、这一场、这一章：把尺度收到作者能立刻回答的大小。

## 第二问：阻力（具体卡在哪一步）

卡在阻力层的信号：作者反复说"感觉不对""写着别扭"；或者作者知道该发生什么，但不肯落笔。

先逼出具体位置，再分类：

- 你是不知道人物接下来会做什么，还是知道但不想这么写？
- 卡在那一句上，把它念出来——是你觉得这句话不像他会说的话，还是你不想让他现在就说这句？
- 如果把这一段删掉直接从下一段写，故事还成立吗？不成立的话，缺的是什么？
- 你现在脑子里有几个版本的走法？分别是什么？

「不知道怎么写」和「不想这么写」是两种完全不同的卡法：
前者缺的是选择，后者缺的是代价评估。分开它们，问题立刻小一半。

## 第三问：代价（这么写要付出什么）

卡在代价层的信号：作者能列出好几个方向，每个都有道理，选哪个都不甘心。

问法：

- 按这个方向写下去，最贵的一笔代价是什么？人物关系、节奏、还是后面某个可能性被关掉了？
- 那个被关掉的可能性，你后面还想不想用？
- 如果这一处写得不够漂亮但故事能继续，你接受吗？
- 反过来，如果这里处理得很爽，但后三章要为此还债，你愿意还吗？

把代价说出口，作者通常自己就选定了——因为作者真正缺的不是选项，而是有人把每个选项的价格标出来。

## 配合本轮注入的材料

追问时别只盯着选中的那一段，对着注入材料找断裂点：

- **未决伏笔账本**：哪条伏笔已经悬了好几章还没兑现？作者卡住的位置，是不是正好卡在这条伏笔该兑现的地方？
- **提到的设定条目**：作者现在写的人物状态、称呼、位置，和条目里记的对得上吗？对不上的地方常常就是卡点。

直接把这些断裂点摆出来问，比"你觉得自己卡在哪"有效得多。

## 三条纪律

- **不代写正文**：可以说"如果是我会问……"，不能写"他会说：……"。正文的每个字都归作者。
- **不替作者拍板**：给出候选方向时要同时给出代价，让作者自己选；作者选完不要评价"这样更好"。
- **一轮一问**：问得越多，作者越答不上来。抓当前最紧的那一层，问透，再走下一步。

## 常见跑偏

| 跑偏 | 改成 |
| --- | --- |
| 直接给出"我觉得应该这样写"的完整方案 | 给出 2 到 4 个方向，各自附一句代价，让作者选 |
| 一次抛出十几个问题让作者做问卷 | 挑当前最紧的一层，一两个问题问到底 |
| 问宏大主题（这个故事想表达什么） | 问这一句、这一场、这一章 |
| 作者答完就顺势往下写一段做示范 | 复述确认，交给作者自己落笔 |
