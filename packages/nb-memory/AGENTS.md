# nb-memory 专属边界

`@notnotype/nb-memory` 是长文本与小说创作的记忆框架，负责 episode 事件、主体注册表、双时间轴状态与检索接口。

## 边界与依赖方向
- 宿主无关：通过可插拔 port（LLM/Embedding/Storage）适配外部环境，严禁引入主应用页面、运行时路径或特定宿主逻辑。
- 独立契约：公开入口保持在 `src/index.ts`，不直接绑定具体产品业务流程。

## 底线与验收
- 干净提交：评测/基准测试（如 `nb-memory-bench`）数据、私有语料和运行产物严禁提交到包目录。
- 保持公开 API、exports 与依赖语义向后兼容。
- 验收标准：改动通过 `bun test` 且无破坏性类型破坏。
