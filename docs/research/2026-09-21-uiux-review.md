# UI/UX 巡视评审 — M1b 壳层（2026-09-21）

> **2026-09 调研档案，决策已落地，仅存档。**

## 评审边界
- 对象：M1b 交付的 I3 作者壳（聊天 / 码字 / 大纲 / 设定 / 新访谈 / 书架），dev server 实机截图 8 张（1440×900）。
- 环境：演示实例未配置模型，**真实 AI 对话体验不在本次评审范围**；本次只评壳层布局、空态、术语与状态一致性。

## 总体结论
**方向合格，细节有 10 项 P1。** 视觉身份（暖米+陶土、全局衬线）统一且辨识度高；设定抽屉（9 分类+描述+计数）与访谈欢迎页是最强的两个屏。问题集中在：空态引导、术语泄漏、状态一致性——全部是「随模块开发顺手修」级别，不建议单独立项修 UI，按下方归属并入 M2 / M2.5。

## 亮点（保持）
1. 新访谈欢迎页：「随时可以开始。今天想聊出点什么？」+ 两张行动卡（先配置模型 / 开始新书访谈），是全app最好的空态范式——聊天空态应向它对齐。
2. 设定抽屉：9 个分类各带一句话描述与条目计数，空分类显示「暂无条目」，信息 scent 充足。
3. 会话 hover 出现重命名/归档操作，发现性好。
4. 书架「需要确认的会话」默认折叠，不打扰主流程。

## 处理建议
- 不单独立项。UX-1/3/4/5 随 M2（聊天与追问主链）修；UX-2/6/7/8/9/10 随 M2.5（码字基本盘 + inline.editor 边界重设计）修；UX-11 并入知识库设计；UX-12/13 记 backlog。
