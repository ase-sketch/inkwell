## 推荐抽屉类目 ↔ 基座类目映射（1:1）

| 抽屉展示（中文） | 基座类目 | 管什么 |
|---|---|---|
| 人物档案 | character | 主角/配角/反派人设与关系 |
| 势力阵营 | faction | 宗门/朝廷/家族/组织 |
| 地理秘境 | location | 世界板块/城池/禁地副本 |
| 神兵宝物 | item | 法宝/丹药/装备/资产 |
| 力量体系 | system | 境界阶梯/功法神通/血脉体质/金手指规则 |
| 世界法则 | world | 天道运转/社会机制/底层规则 |
| 大事记 | event | 历史事件/战役/剧情节点 |
| 暗线备忘 | note | 伏笔钩子/随笔/待整理碎片 |
| 写作规范 | instruction | 文风偏好/创作禁忌/防 OOC 指令 |

## 呈现原则（从调研与用户反馈收敛）

1. ~~空类目组不显示~~（2026-09-21 废弃：用户新书试用时以为条目丢了——9 个类目平时全部露面，空类目标注「暂无条目」；搜索态仍只列命中类目）；组头 = 中文名 + 一句话定义
2. 条目摘要用自身 frontmatter summary，没有就不显示——**禁止英文占位摘要**（"Character lorebook category." 这类）
3. 技术状态词（已生效/草稿中）不对作者裸露
