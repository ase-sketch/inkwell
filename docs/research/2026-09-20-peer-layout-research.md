# 同类项目布局与信息架构调研（2026-09-20，第二轮）

> 视角：M1b 布局重排专用——首屏空态 / 栏位划分 / 聊天与编辑器关系 / 功能分组 / 设置入口。
> 四路来源：Codex 桌面版（u4，钦定蓝本）、头部小说应用（u1）、桌面写作工具（u2）、DSH 插件工作台（u3）。

## 一、跨报告共识（≥3 路独立提到）

1. **极窄图标栏**：OpenFic 48px 图标栏、墨参 10 图标窄轨、Codex 左栏底部齿轮——一级导航全部图标化，把横向空间让给主区
2. **主区情境互换**：Codex（编辑器非常驻、diff 走抽屉）、oh-story-dsh（按需激活+一键收回纯对话）、墨参（对话/写作两全屏页平级互换）、easy-writing（AI 顾问右侧伴随抽屉）——对话与码字不硬挤一屏
3. **静态资产入抽屉**：Codex 右侧抽屉、NextTavern「酒馆管理」抽屉（6 模块）、inkos HUD 面板、easy-writing 资料五件套抽屉/全屏双层——设定/角色/大纲不常驻主屏
4. **设置 1-2 步直达**：几乎全部项目是侧栏底部齿轮一步达；对照基座要翻配置中心，差距明显
5. **首屏不做空白表单**：inkos 创作形态卡、Biz Novel Studio 向导、51mazi 书架网格、oh-story 空目录纯对话——空态给「下一步该做什么」
6. **提案卡确认制再次被强化**（Vela Proposal 收件箱、墨参加入/忽略卡、show-me-the-story 事实变更提案、inkos Action 卡）——已在访谈中拍板**不进 M1b**，独立立项

## 二、各项目要点（按价值摘记）

### Codex 桌面版（蓝本，u4）
- 左栏：+ New Thread / Automations / Skills / 会话列表（带运行状态）/ 底部头像设置
- 中间：全宽执行流；编辑器非常驻，diff/文件走右侧抽屉
- Composer 控制台化：模型切换、模式开关、Token 占用条全在输入框底边
- 设置：左下角头像或快捷键，1 步达
- 三种共存摆法对照：IDE 附庸型（Cursor）/ 调度中心型（Codex）/ **情境互换型（ChatGPT Canvas）——深度人机协同创作的推荐形态，即 Q4 已选**

### 头部小说应用（u1）
- **inkos**（~10k）：对话流内嵌结构化 Action 卡；右侧 HUD 展示世界状态
- **AI-Novel-Writing-Assistant**（~3k）：顶部常驻「下一步建议」栏；世界观「门面摘要+全屏手册」双层
- **NovelForge**（~1.2k）：Schema 卡片树；字段级流式填充，单项修正再落库
- **OpenFic**（~1.1k）：48px 极窄图标栏 + 居中沉浸编辑器 + 可折 Agent 浮层 + 极轻底部状态栏；设置齿轮在图标栏底部 1 步达
- **AI-Novel-Writer/Vela**（~1k）：Proposal 待审收件箱；8 步阶梯进度模型

### 桌面写作工具（u2）
- **easy-writing**（~600，码字主场标杆）：**写作与模型配置彻底解耦——没配 Key 也能建书开写**，模型引导是温和卡片非阻断门禁；三栏：卷章树 / TipTap 沉浸编辑器（音效/专注模式）/ 右侧「妙笔对话」AI 顾问抽屉
- **vela**：VSCode 四分屏——**反面教材**，印证 IDE 壳认知过载
- **51mazi**：划词才滑出右侧 AI 抽屉；地图/图谱切全屏画布不挤侧栏
- **墨参**：双轨窄侧栏 + 主区整页互换；提案卡（加入/忽略）；**正文实体自动标蓝+浮卡**（码字体验亮点，远期参考）
- **show-me-the-story**：顶部阶段管线导航；事实变更提案制
- **denova**：Subagent 状态收进侧面板显式管理，不污染主对话流

### DSH 插件工作台（u3）
- **oh-story-dsh**：空目录纯对话，产出首文件才激活工作台；一键收回纯对话；**文件跟随**（Agent 改哪章编辑器自动跳转高亮）
- **Openwrite**：90 工具收敛为 3 个顶级 Tab（创作/资料/任务）+ 对话流卡片；Goethe 规划 → Dante 写作两阶段 handoff
- **NextTavern**：「酒馆管理」单抽屉收 6 模块；消息级世界线分支条
- **dsh-novel-writer**：改稿台 = 带行号/锚段/目标差值的 12 条优先级待办（M3 直接参考）

## 三、对 M1b 的输入结论

1. 布局骨架 = **极窄图标栏 + 会话列表 + 主区情境互换 + 右侧抽屉**（四路共识叠加 Codex 蓝本）
2. 引导卡要**温和不阻断**（easy-writing 教训）：未配模型可先看界面，引导卡常驻直达配置
3. 首屏双入口：「开始新书访谈」/「打开已有文稿」，不给空白 IDE
4. Composer 控制台化与底部状态栏列入 M1b 候选，按工作量裁剪
5. 文件跟随、实体标蓝、改稿台待办化 → 记入 M2/M3 备选池，不在 M1b
