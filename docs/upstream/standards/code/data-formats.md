# JSON 与 YAML 数据格式

适用：`.json`、`.jsonc`、`.yaml`、`.yml` 配置及其生成器；同时读取配置所属领域的规范。

- 使用解析器修改结构化数据，保持现有缩进、键顺序和尾随换行。JSON 使用标准语法，不加入注释或非标准值。
- 新字段定义默认值、缺失语义、版本兼容和秘密边界。环境变量区分未设置与空字符串。
- 生成输出确定性排序；同一输入必须产生字节稳定结果，避免无意义 diff。
- Workflow、Issue Form、产品配置和发布元数据运行各自已有合同检查；语法可解析不等于行为合同通过。

完成标准：目标格式可由正式解析器读取，新旧缺失语义明确，生成结果确定性，并通过所属领域的合同校验。
