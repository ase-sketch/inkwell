# TypeScript 脚本规范

适用：`scripts/**/*.ts`、`scripts/**/*.mjs`。通用与 TypeScript 规则由 [`../README.md`](../README.md) 路由；发布等子目录合同由最近的 `AGENTS.md` 补充。

- 脚本是 CLI、CI、构建、安装、部署和维护的编排入口；领域逻辑进入拥有该能力的模块，脚本保留参数解析、调用和结果投影。
- CLI 定义稳定参数、退出码、stdout/stderr 分工和确定性输出；机器消费输出使用 versioned JSON，不混入进度文本。
- 文件、Git、进程和网络操作使用参数数组与结构化 API；目标路径先归一化，外部命令保留原始退出码和 stderr。
- dry-run 必须执行与真实路径相同的解析和选择，只跳过最终副作用；中断后可判断已完成边界，避免重复发布、迁移或写入。
- CI 检查失败项包含文件、目标和具体合同；新增命令进入 `package.json`、类型检查 include、工作流或调用方的现有入口。

完成标准：CLI 参数和退出码有合同测试，dry-run 与真实选择一致，所有副作用可定位且失败可恢复，脚本类型检查通过。
