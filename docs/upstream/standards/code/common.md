# 通用编码基线

本文件只保存所有源码改动都必须应用的规则；语言和领域规则由 [`README.md`](README.md) 路由。

## 实现

- 先读相邻实现、测试、配置和公开合同，沿用已有模块、命名、错误、日志和测试工具。抽象必须减少真实重复、复杂度或所有权歧义；单调用 wrapper 不进入代码库。
- 外部输入在系统边界解析、校验和归一化。失败尽早、明确且可诊断；缺配置、权限、引用或前置产物时返回现有错误合同。
- 保存、网络、进程、迁移和跨语言边界必须定义成功、失败、清理与重试所有权。迁移完整切换消费者并删除旧入口。
- 热路径避免可省的分配、复制、序列化、目录扫描和重复计算；缓存必须有失效与所有权合同。
- 日志使用结构化字段和自然语言消息；秘密和大正文只记录尺寸、摘要或脱敏标识。

## 测试与注释

- 测试覆盖可观察合同、边界、状态转移和真实失败，不匹配源码字符串、私有调用顺序或偶然默认值；临时数据遵循 [`../../testing/README.md`](../../testing/README.md)。
- 注释解释调用合同、所有权、时序、平台差异、安全边界、资源生命周期和非显然取舍；公开接口说明用途与失败语义。
- 新职责进入拥有该职责的现有模块。除已登记硬上限外，按所有权、状态机和平台边界判断是否拆分，不用机械行数代替设计审查。

完成标准：本次改动沿用一个现有所有权模型，每个外部边界、失败路径和资源生命周期都有实现或测试证据。
