# 文档模板分档治理

仓库的文档结构约束目前只有两个极端：`docs/specs/` 中 `kind: behavior` 的规范被强制要求九个章节且每章不得为空，而 `docs/standards/` 完全没有模板、frontmatter 或检查。九章模板按运行时功能剪裁，描述标准、规则或政策类文档时会产生占位章节；零约束一侧则只能靠自觉维持一致。

本 Work 调查两侧现状，提出按文档类型分档的结构约束方案，使每类文档拥有刚好够用的结构，而不是九章或零章。
