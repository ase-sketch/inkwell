# t02 v4.1 Viewer 迁移最终闭环

## 结论

第一章小说记忆 spike 已闭合 v4.1 的页面、数据、算子与构建链路。`Slot.subject` 统一为 `{ type: "entity" | "kind", id }`；粗分类从已删除的 `Entity.facet` 迁移到 `Kind.category`；`viewer.html` 保留独立求值与校验、叙述位置切片、图谱、检视器、拖放重载和中文界面；`chapter-01-graph.html` 由 `build-viewer.ts` 注入 schema.ts 派生结果，已不再读取 `e.facet`。

任务目录内的 canonical 计数为：9 个 Kind、10 个 Entity、32 个 Predicate、50 个 Slot、66 条 Disclosure、24 个 Beat、3 条 Scene、5 个 Moment、4 条 MomentRelation、77 段正文。第 1 段的标题披露挂在 Kind 槽，因此读者位置切片显示 Entity `0/10`，与 `entityKnownAt()` 语义一致。
