# 第一章摘要提示词修订候选 v3

> 状态：待开发者审查，未用于真实模型调用。
> 基线：v1 模型原文、调用统计、v2 提示词和首份人工稿均保留。
> 目标：L1 正文与可选写作提示合计少于原文可见字数的 `50%`；本章硬上限为 `1000` 可见字。

## 共同事实边界

```text
只写原文明示或能直接确定的内容。可以保留角色原文明示的心理、判断、误解和情绪，但必须归属于角色；不得补充摘要者的主观动机、因果、评价或后续推测。原文含混时摘要也保持含混。
```

## L1：作者写作指令型缩句稿

提示词版本候选：`chapter-summary-level-1/v3`

```text
输出一份供作者驱动写作模型使用的高保真缩句稿。

硬约束：
- 正文、系统写作提示和已有作者批注合计必须少于原文可见字数的 50%；本章少于 1000 可见字。
- 保持原场景顺序、倒叙/插叙位置、信息揭示顺序和章末落点，不得改排为时间正序。
- 保留影响人物认知、选择、冲突、设定或后续写作方向的心理和剧情步骤，但压缩动作、外貌、感官、笑料与重复反应。
- 不要求保留全部台词。只有承担人物声音、决定、契约、身份揭晓或关键反转的短台词保留原句；其余对话客观转述。
- 原文明示的心理可以缩写或转述，但必须标清角色归属，不能写成客观事实。

可选批注与写作提示：
- 如果输入中已有作者明确提供的批注，可在不改意的前提下保留为“作者批注”；模型不得自行生成或扩写作者批注。
- 模型从原文提取的内容统一标为“写作提示（系统提取）”，最多 3 条，只用于压缩正文难以稳定传达的非线性叙事、延迟揭示、视角、人物声音或章末落点。
- 系统写作提示只写可从原文直接观察的约束，不解释主题，不猜创作意图，不冒充作者意图，并计入字数上限。

直接输出缩句稿；不要标题、分析、评价或前后说明。
```

## 验收

1. 总可见字数 `<1000`，且输出保留率 `<50%`。
2. 开场、回忆插入点、返回当前场景、延迟揭示与章末状态均可复原。
3. 关键原话数量受控；删除任一保留原话都会损失人物声音、选择或转折。
4. 每项心理均有原文直接依据并归属于角色。
5. 系统写作提示不超过 3 条，且没有生成、扩写或冒充作者批注。
